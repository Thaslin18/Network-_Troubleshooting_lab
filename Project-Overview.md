# Project Overview

## Title
Network Troubleshooting & Monitoring Lab — Windows

## Background
Network administrators need a consistent process to diagnose connectivity complaints. A user may report that “the internet is not working,” but the actual cause may be a disconnected adapter, an incorrect address, a gateway problem, DNS failure, routing issue, or a specific service being unavailable.

## Problem statement
Unstructured troubleshooting can lead to unnecessary configuration changes and longer outages. This lab provides a repeatable diagnostic checklist and practical Windows commands to collect evidence before taking action.

## Goals
- Understand common Windows network settings.
- Learn to distinguish local, gateway, DNS, routing, and service-level issues.
- Use built-in diagnostic utilities.
- Write clear incident records and verify a resolution.

## Tools
- Windows 10/11
- Command Prompt
- Windows PowerShell
- Built-in utilities: `ipconfig`, `ping`, `nslookup`, `tracert`, `arp`, `route`, `netstat`, `Get-NetAdapter`, `Get-NetIPConfiguration`, `Test-NetConnection`

## Deliverables
- Seven scenario guides
- Command reference and glossary
- Read-only diagnostic collection script
- Incident-report template and sample log
- Troubleshooting flowchart and small-office topology diagram
- Illustrative command-output images

## Success criteria
A learner can follow the workflow, identify which evidence to collect, explain what common outputs mean, avoid jumping to conclusions, and record a concise incident report.
