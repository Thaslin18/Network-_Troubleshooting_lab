# Networking Glossary

- **IPv4 address:** 32-bit address used to identify a host/interface on an IP network.
- **Subnet mask / prefix:** Defines which addresses are local to a subnet.
- **Default gateway:** Router used to reach destinations outside the local subnet.
- **DHCP:** Automatically provides IP configuration to clients.
- **APIPA:** Self-assigned IPv4 range `169.254.0.0/16`, often seen when DHCP configuration is unavailable.
- **DNS:** Resolves hostnames to IP addresses and other records.
- **ARP:** Resolves local IPv4 addresses to link-layer MAC addresses.
- **Route:** A rule that determines the next hop/interface for traffic.
- **TCP:** Connection-oriented transport protocol.
- **Port:** Number identifying a service/application endpoint at the transport layer.
- **ICMP:** Control/diagnostic protocol used by tools such as ping.
- **Latency:** Time taken for traffic to travel and return.
- **Packet loss:** Traffic that does not arrive as expected.
- **NIC / network adapter:** Hardware or virtual interface connecting a device to a network.
